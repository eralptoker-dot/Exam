Q1 Answer: Within the db_push function, I allocated each song separately with malloc, with unique allocations for each title. The addresses of the first and second song pointers (with titles) are thus not contiguous in memory, also the absolute difference for two song addresses is not equal to sizeof(Song). For my run, the two Song addresses were 320 bytes apart, with sizeof(Song) being 40 bytes.
Q3 Answer: *(const Song **)a The ** in cast is used for pointer-to-pointer. The first * is for a dereference so I can obtain the Song pointer. So first unwraps to get the actual Song address within the array slot. If we cast a directly to const Song *, array slot would be categorized as a Song. Now we have a pointer to the Song in that spot.
Q4 Answer : a. For db_destroy, I realized I was leaking memory because I was initially only freeing the song array and its titles (traced db_destroy and realized it skips artist -> songs), which is problematic because the song pointer arrays within Artist structures are dynamically resized. I then iterated through all artists individually (and freed their song arrays).
b. Program used to crash when malloc and realloc failed in db_push/ekle_artist functions (I then went line by line to discover there were no checks/fixes for it), so I added NULL checks (ekle_artist) to ensure -1 is returned (db_push) on failure for memory allocation checks.
